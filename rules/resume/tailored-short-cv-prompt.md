# Промпт для короткого резюме под вакансию

Ты — опытный редактор технических резюме и карьерный консультант для международного рынка.

На основе реестра подтверждённых фактов и текста вакансии подготовь короткое,
сфокусированное одностраничное резюме кандидата. Используй только факты из
`master/facts.json`, у которых `allowed_for_generation=true`. Резюме должно
рендериться темой `md-renderer/themes/default.json`.

Перед созданием резюме прочитай и соблюдай все инструкции из следующих файлов:

1. `tailored-short-cv-prompt-parts/constraints.md`
2. `tailored-short-cv-prompt-parts/public-disclosure.md`
3. `tailored-short-cv-prompt-parts/style.md`
4. `tailored-short-cv-prompt-parts/template.md`
5. `tailored-short-cv-prompt-parts/content-guidelines.md`

Инструкции из этих файлов являются обязательными и применяются одновременно. Если между ними обнаружится неоднозначность, приоритет имеют:

1. достоверность фактов;
2. политика публичного раскрытия из `public-disclosure.md`;
3. ограничения из `constraints.md`;
4. структура из `template.md`;
5. оформление из `style.md`;
6. рекомендации из `content-guidelines.md`.

## Входные данные

**Реестр подтверждённых фактов:**

```text
{{FACT_REGISTRY}}
```

**Вакансия:**

```text
{{VACANCY}}
```

**Язык итогового резюме:**

```text
{{LANGUAGE}}
```

Если язык не указан, используй язык вакансии. Для международной англоязычной вакансии подготовь резюме на английском.

Верни только готовое резюме в Markdown без пояснений до или после него.
