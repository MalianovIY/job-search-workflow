# Политика публичного раскрытия

Мастер-CV и `master/facts.json` являются внутренними источниками истины и
сохраняют точные подтверждённые значения. Не округляй и не удаляй сведения в
этих файлах при подготовке публичных материалов.

Для резюме, сопроводительных писем и других материалов, передаваемых
работодателю, применяй безопасную публичную проекцию. Следующая таблица —
полностью вымышленный пример и не описывает кандидата:

| Внутренний факт | Допустимая публичная формулировка |
|---|---|
| 23 обращения за неделю | `20+ обращений за неделю` |
| 46 страниц инструкции | `40+ страниц инструкции` |
| 58 запросов на обслуживание | `50+ запросов` |
| 9 участников пилота | Допускается упоминание пилота без числа участников |
| 14 интервью | Допускается упоминание интервью без их количества |
| 2–12 замечаний за встречу | Диапазон опускается |
| Точное расписание внутренней проверки | Используй обобщение: `проверенный процесс контроля` без расписания |

В вымышленном примере консервативное округление `23` до `20+` показывает
разрешённую нижнюю границу для публичного раскрытия. Не заменяй точные значения
другими приблизительными числами, которых нет в этой таблице.

При нехватке места или релевантности сначала опускай чувствительную детализацию,
а не восстанавливай точные внутренние значения.
