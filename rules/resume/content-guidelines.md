# Правила адаптации содержания

## Основная задача

Выбери из мастер-CV только наиболее релевантные вакансии опыт, проекты, достижения и технологии. Расставь материал по значимости для конкретной роли.
Перед использованием количественных фактов примени публичную проекцию из
`public-disclosure.md`.

## Professional Summary

- Напиши один плотный абзац из 3–5 предложений.
- Сразу обозначь целевую роль и релевантный стаж.
- Укажи наиболее подходящие домены.
- Выдели 2–4 сильнейших преимущества кандидата для вакансии.
- Используй от 2 до 4 числовых якорей включительно. Не превращай summary в
  перечень метрик.
- По возможности выбирай якоря разных типов. Результат добавляй только
  тогда, когда он действительно сильный и подтверждённый.
- Годы, проценты и количественные масштабы считаются числовыми якорями.
- Не повторяй дословно весь блок навыков.

## Core Skills

- Оставь 4–6 тематических строк.
- Расположи группы и технологии по степени релевантности вакансии.
- Включай только навыки, подтверждённые мастер-CV.
- Каждую тематическую группу записывай одной исходной Markdown-строкой и
  подбирай её длину так, чтобы она занимала ровно одну визуальную строку в PDF
  при рендере через `md-renderer/themes/default.json`.
- Каждая визуальная строка должна начинаться с коротких обобщающих слов,
  оформленных как жирная категория с двоеточием. Строки-продолжения без
  категории недопустимы.
- Если группа не помещается, сначала убирай менее релевантные технологии или
  сокращай точную формулировку категории. Не уменьшай шрифт и не допускай
  горизонтального выхода за поля.

Формат каждой строки:

```md
**{{КАТЕГОРИЯ}}:** {{ПОДТВЕРЖДЁННЫЕ_НАВЫКИ}}
```

## Professional Experience

- Сохраняй реальную обратную хронологию, названия компаний, должности и даты.
- Для наиболее релевантного места работы используй 4–5 пунктов.
- Для остальных мест работы используй 1–2 пункта.
- По умолчанию оставляй три наиболее релевантных места работы.
- Общий ориентир — 8–12 achievement bullets.
- При необходимости оставь отдельный подраздел с особенно релевантными проектами.
- Убирай второстепенные детали, не усиливающие соответствие вакансии.
- Отдавай предпочтение достижениям, где видны масштаб, техническое решение и результат.
- Не меняй официальную должность только ради совпадения с названием вакансии.
- Если в реестре указана только функциональная роль, явно обозначай её как
  функциональную и не выдавай за подтверждённую должность из HR-системы.
- Не добавляй готовность к remote, отрасль работодателя или ownership, если
  этого нет среди разрешённых фактов.

## Education и Languages

- Используй компактный формат из шаблона.
- Не добавляй новые сведения.
- Не расширяй эти разделы, если информация не влияет на соответствие вакансии.
- Для одностраничной версии объединяй каждую запись образования в одну визуальную строку.
